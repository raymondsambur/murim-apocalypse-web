## Build
1. **Places**: assign every living NPC (at spawn and when `npcBorn`/`npcMoved` events arrive) a **home** (a house in their settlement; share houses among 1-4 NPCs by family/age; guards use barracks if present, innkeepers live at the inn) and a **workplace** by role (smith -> smithy, alchemist -> alchemy, merchant -> market, innkeeper -> inn, guards -> gates/plaza/towers patrol points, masters -> dojo/hall/pagoda, elder -> plaza/hall, farmers/villagers -> farm patches, herb huts, or the plaza). Also shared spots: inn (eat/socialise), plaza, shrine, well/market stalls. Use `world.buildings` doors as entry points and `isPassable` tiles around them. Deterministic from seed/ids; persist nothing that can be re-derived.
2. **Schedule + needs (utility AI)**: each NPC has needs (hunger, rest, company, devotion, safety, duty) that grow over time and are satisfied by activities. Every few world minutes (not every tick) pick the best-scoring activity from: sleep (at home, entity hidden inside), eat (inn/home), work (at workplace), socialise/chat (with a nearby NPC, both stand close and face each other), pray (shrine), sweep/tidy (near home), train (masters/guards), trade (merchants at stalls), patrol (guards), idle wander. Scores combine need, a default schedule table by role and world hour (world clock via `ctx.sim.clock()`; one world hour = 1 real minute at default pacing, so activities last a few real minutes), personality traits (devout pray more, cheerful socialise, weary rest earlier, gruff chat less, greedy work longer), weather (`ctx.sim.weatherAt`), and the settlement's state (`ctx.sim.settlementView`: besieged/fallen/famine/festival flags).
3. **Movement**: NPCs walk between places using `ctx.movement.moveTo` with realistic pacing (slower speed than players, pauses), arriving at doors then disappearing inside (`entity.hidden = true`) for sleep/indoor activities and re-emerging; never teleport in view; stagger so crowds don't move in lockstep; **bounded per-tick work** (only NPCs near players need frequent updates; others can be updated lazily/abstractly and placed correctly when a player approaches - define a simple LOD: far NPCs are snapped to the location their schedule says when they come into range).
4. **Cue to clients**: set `entity.act` (`NpcAct`) to match the current activity while the NPC is standing and doing it (work/eat/chat/pray/sweep/rest/patrol/trade/train/shelter/mourn/celebrate), clear it while walking, then `ctx.entities.touch(e)`. Set `entity.state` sensibly (`work` for work-like activities).
5. **Reactions** (via `ctx.onHour(events)` and settlement views): rain/storm -> villagers shelter indoors or under eaves; night -> most go home, guards patrol, an innkeeper stays open until late; **siege or Blight alarm** -> guards rally to gates (act patrol/work), villagers flee indoors, shopkeepers close; **famine** -> NPCs gather at the market and mope; **festival** flag or season change -> crowd gathers in the plaza (`celebrate`); NPC death -> neighbours gather and `mourn` for a while near the home; dawn/dusk transitions with stragglers.
6. **Determinism and cost**: use `ctx.rng` and `ctx.now()` only; tests deterministic via the harness; per-tick cost O(active NPCs near players); document the constants (`NPCLIFE_TUNING`).
7. **Observability**: expose `getNpcLife(ctx)` returning a read-only API (`activityOf(npcId)`, `placesOf(npcId)`, `npcsAt(placeKind, settlementId)`, `nearbyNpcs(npcId)`) for the memory/gossip engineer and tests; also emit an event on the bus for conversations: `npcChat: { a: number; b: number; settlementId: number }` (declare it in your own file via declaration merging) so the gossip system can later hook in.
