### Visual identity
Ink-wash dark UI with parchment panels, gold (`#d9b867`) and cinnabar (`#c8452d`) accents, subtle paper/ink textures from CSS (gradients, SVG data URIs, shadows - no image files), serif headings (system stack: "Palatino Linotype", "Book Antiqua", Georgia, "Noto Serif CJK SC", serif), CJK glyphs as icons (items/skills carry a `glyph` in shared data), rarity colours from `RARITY_COLORS`. A small design system in `styles.css` (CSS variables, buttons, bars, tabs, panels, tooltips, scrollbars, toasts, focus rings). Polished, not a developer prototype. Respect `prefers-reduced-motion`.

### Screens and flow (`main.ts`)
`GET /api/me` -> logged out: **Auth screen** (login/register tabs, inline validation matching server rules: username 3-20 `[A-Za-z0-9_]`, password 8-72; friendly errors; animated ink-wash/mountain-mist background via CSS/canvas; title "Murim Apocalypse" brush-like, one-line tagline). Logged in without a character -> **Character creation** (`POST /api/character/roll`: first roll free, then rerolls with remaining count; animated bars for the six stats, talents (good/bad colouring), origin card with starting items/skills, fate line; appearance pickers (gender, skin, hair style/colour, outfit, outfit colour, sash colour, accessory) with live preview via `RenderModule.drawLookPreview` and `lookSwatches`; name field with live validation; "Randomise look"; Create). Then **enter game**: fetch `/api/world`, decode base64 grids into `DecodedWorld`, create the `GameView`, open the WebSocket, handle `hello`, show the game screen. Handle disconnects (overlay "Connection lost - reconnecting", exponential backoff, re-hello), `kick`, logout.

### Game screen (desktop + mobile)
Full-viewport canvas under HUD overlays:
- Top-left **player card**: small portrait (`drawLookPreview`), name, rank + stage (`levelLabel`) in rank colour, HP / Qi / XP bars with numbers, gold, injury indicator. Top-right: **clock** (day, season, time-of-day icon, weather) and the **minimap** (tap centers the camera via `centerOn`).
- Bottom: **chat dock** (collapsible; tabs Local/World/Sect/Whisper/System with unread badges; input with channel selector and `/w name msg`, `/world msg`, `/sect msg`; messages show tag + rank colours; speech bubbles via `GameView.say` for local chat; last 200 per tab) and an **action bar** with panel buttons + hotkeys (C character, I inventory, K skills, M missions, J jobs, O world, F social, Esc closes), collapsing into a bottom sheet / hamburger on narrow screens.
- **Toasts** for `note`; forward `combat`/`cfx`/`fx` messages to the renderer (`combatEvents`, `fx`).
- **Interaction**: tap tile -> `{t:'move'}` + `setMoveTarget`; tap entity -> select (`setSelected`) and show a small **context card** (name, level, hp, tag; buttons Talk / Attack / Gather / Inspect by kind/role -> `interact`), right-click/long-press = quick default action. Players: Inspect (query `player`), Whisper, friend/sect invites (wire to messages), Duel.
- **Combat HUD**: when `me.combatId` is set or `combat` messages arrive: both sides' fighters (HP/Qi bars, status icons), scrolling event log in words (skill names from shared data), **Flee** button (`{t:'flee'}`), auto-hide on `cend`, result banner (victory/defeat/fled + rewards).
- **NPC dialog** (`S2C npc`): portrait, greeting, tabs as available: Shop (buy list with prices, sell list from inventory via `sell`, quantity steppers), Teach (skills with requirements/gold/Learn, disabled reasons), Missions (settlement board via query `board` with Accept; turn-in buttons for `turnIns`), Rest (inn), Disciple request. Built against the protocol and the mock (server features arrive later).
- **Death overlay** when hp is 0 / state dead.
